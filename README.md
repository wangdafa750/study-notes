## 目录结构

每个笔记一个子文件夹，包含：

- `main.tex` — 笔记源码
- `preamble.sty` — 全局样式（Nord 配色，自定义 定理 / 例子 / 避坑 / 代码块 环境）
- `main.pdf` — 编译产物

## 如何编译

需要 TeX Live（含 `ctex`、`tcolorbox`、`tikz` 等宏包）：

```bash
cd Git笔记
xelatex main.tex   # 编译两遍以生成正确的书签
```
